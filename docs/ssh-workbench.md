# 内置 SSH 节点工作台使用手册

适用范围：pi-web-ui 安装在 macOS 或 Windows 客户端，本机服务经 SSH 连接 Linux/macOS 节点。节点上的账号或容器提供实际的权限边界。工作台内置于顶栏「SSH 节点」，无须安装 Remote-SSH 插件。

## 准备节点

远端要运行 SSH 服务，客户端应能访问其地址与端口。先在客户端终端确认基础连接：

```bash
ssh -p 22 user@your-host
```

建议给工作台使用单独的远端账号，并按需要限制该账号或容器的文件和命令权限。工作台的 Agent 会在已连接节点上自动执行命令，不逐条请求确认。

如果用密钥认证，先在客户端创建密钥，并把公钥加入远端账号的 `~/.ssh/authorized_keys`。例如：

```bash
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_pi_nodes
ssh-copy-id -i ~/.ssh/id_ed25519_pi_nodes.pub user@your-host
```

`ssh-copy-id` 并非每台 Windows 客户端都有；可用管理员提供的方法安装公钥。工作台里的“私钥路径”填写**客户端本机**私钥的路径，如 macOS 的 `/Users/you/.ssh/id_ed25519_pi_nodes`，或 Windows 的 `C:\Users\you\.ssh\id_ed25519_pi_nodes`。选择 SSH agent 认证时，先确保运行 pi-web-ui 的用户进程能访问已加载密钥的 agent。

## 新增并连接

1. 点击顶栏「SSH 节点」，再点左栏 `＋`。
2. 填写分组、名称、地址、端口、用户名和远端默认目录。默认目录使用远端绝对路径，例如 `/home/user/project`。
3. 选择「密码」「私钥」或「SSH agent」。密码方式填 SSH 密码；私钥方式填本机私钥路径，若密钥加密再填口令。
4. 保存节点，在左栏选中并点击「连接」。第一次连接会显示主机密钥 SHA-256 指纹。通过可信渠道与服务器指纹核对，确认后再信任。可在远端服务器上由管理员运行 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256` 核对对应密钥；服务器可能提供其他类型的主机密钥，请核对工作台实际显示的类型和指纹。
5. 如果主机密钥变化，工作台会阻止连接。先核实是否为有意换钥；核实后在节点编辑窗口点「清除主机密钥信任」，下次连接重新核对指纹。

节点信息和已信任指纹保存在本机数据目录；密码和私钥口令存入本机加密存储。macOS 与 Windows 两台客户端各自保存资料和凭据，不自动同步。

## 终端、文件与 Agent

连接后点击中栏标签栏的 `＋` 新开 SSH 终端。每个标签是一条独立 shell；切换节点或标签时，要先确认右侧显示的节点名称和输入区显示的终端标签。断线标签会标记「断开」，无法继续输入；重连后新开终端。

终端下方输入远端绝对路径并点「浏览」，使用 SFTP 查看目录。点文件可读取文本并编辑，点「保存」写回远端。单次读写上限为 512 KiB；编辑前请自行确认远端文件权限与备份需求。

右侧节点 Agent 的对话按节点独立保存。发送消息前必须选中一个已连接的手动终端。Agent 命令会进入该终端的现有 shell，保留当前目录和 shell 环境；执行期间锁定人工输入。若 shell 有前台任务，工作台会先发 Ctrl+C，确认回到提示符后再执行；确认失败则停止并报错。执行过程可点「中断」或「停止 Agent」。远端命令输出在终端可见，也会进入 Agent 对话记录。节点 Agent 仅提供绑定该节点的远端命令与文件工具，不使用本地工作区工具。

## 导入、导出和迁移

- 左栏「导入 Remote-SSH 配置」读取旧版插件的主机资料，原插件配置不删除。旧凭据不导入，需在节点编辑窗口重新填写。
- 「导出节点 JSON」仅包含非机密主机资料，不含密码、私钥口令和已信任指纹；可在另一台设备用「导入节点 JSON」导入后重新配凭据并核对指纹。
- Xshell 的会话文件不能直接导入工作台。可参照 [Xshell 与 SSH 连接手册](xshell.md) 手动填写同一台服务器的地址、端口和用户名。

## 常见问题

| 现象 | 检查项 |
| --- | --- |
| 连接超时或拒绝 | 远端 SSH 服务、地址、端口、网络与防火墙；先用系统 `ssh` 命令排查。 |
| 认证失败 | 用户名、密码、私钥路径、口令或 SSH agent 是否属于运行 pi-web-ui 的用户。 |
| 主机密钥变化 | 停止连接，独立核实远端是否换钥；不要仅凭弹窗清除信任。 |
| Agent 提示无法确认 shell | 终端可能仍在 vim、交互程序或卡住的前台任务中；手动恢复 shell 提示符后重试。 |
| 文件无法保存 | 检查远端账号对该路径的权限，以及 512 KiB 限制。 |

实现和安全边界见 [架构说明](architecture-nodes.md)。
