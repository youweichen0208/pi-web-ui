# 工作区界面

Web 与 Electron 共用同一套 React 布局与 `web/src/styles.css`。本次视觉参考为用户提供的 `pi-web-ui-standalone.html`（完整可运行参考），示例项目、消息和模型均由真实服务端数据替代。

- 左侧全高项目栏默认 264px：品牌、新对话、项目及当前项目的会话、设置（菜单中包含语言切换）。项目和会话行默认显示时间，悬停或键盘聚焦时以单个“更多”按钮替换时间；重命名、删除和移出项目都在菜单内，删除／移出须二次确认。项目显示展开箭头与会话数，折叠后保留计数；路径仅在悬停提示中显示，根目录与用户主目录分别显示为“根目录”和“~”。未手动命名的已完成问候会话在中文界面显示“打招呼”，顶栏与侧栏保持一致。
- 主区顶栏高 52px：项目／会话标题、对话／终端／Git／后台任务与文件栏开关；非 Git 仓库时 Git 标签置灰并提供原因提示。
- 对话内容与输入框最大宽度 780px。消息滚动区顶部以 16px、底部以 56px 渐隐过渡；输入栏在滚动区外，末尾保留 24px 空间，短对话从底部向上排。用户消息靠右、浅紫底；模型与带“思考”标签的思考强度位于输入框底部，模型菜单向上展开。
- `/reload` 在对话中显示浅紫色等宽命令气泡和居中事件：进行中显示跳动点，完成时显示扩展／技能／提示模板数量与耗时，加载诊断以琥珀色提示并可展开路径和错误。悬停显示加载资源名称。其他通知位于输入框正上方，普通通知 3 秒消失，错误和警告保留到手动关闭；快捷键提示只在空输入框获得焦点时出现。
- 文件栏默认 272px，可拖动调整及收起。目录原地展开，缓存已读取的节点；目录请求串行发送，切换项目清空缓存，隐藏时停止刷新。有“本次对话涉及”时，文件树按内容占用最多 45% 高度，涉及文件列表使用剩余高度并独立滚动。Git 状态使用独立的负数请求 ID，与 SCM 面板隔离；目录以数字标记改动数量，文件以 M/A/D 标记改动类型；“只看改动 (数量)”保留改动文件和祖先目录。非 Git 状态只在底栏显示；底栏路径对常见用户主目录使用 `~` 缩写。连接、分支、消息和路径统一放在全窗口底部的 32px 状态栏，避免出现两条高度不同的状态栏。
- 宽度 ≤1100px 时文件树使用抽屉。769–1200px 打开文档会收起项目栏，编辑器默认占剩余宽度的 45%，可拖动分隔条调整、双击恢复默认；可通过顶部按钮临时打开项目栏。≤768px 使用移动端抽屉。
- Bash 工具卡片采用浅色命令区与深色输出区，默认显示 8 行，提供行号、路径分色、展开剩余行、换行和真实剪贴板复制。思考块结束后可折叠查看正文；有记录的真实耗时从 1 秒起显示，未记录时不显示计时。服务端按对话、消息和块记录本次运行计时。
- 设置与目标入口收进左下角设置菜单；窄屏移至顶栏更多菜单。思考模式显示“极简／标准／深度”，按模型支持的级别发送，精确级别仍可在模型菜单内选择。
- 暖灰背景、深灰文字、紫色强调色；保留原紫色 π 图标。字体使用本地 IBM Plex Sans 与 JetBrains Mono，中文回退至系统字体。字体文件及许可证在 `web/public/fonts/`。
- 原文档编辑能力保持：15px 正文、浅色代码块、高亮块、图片细边框；`/` 菜单仅在普通空段落开头触发，列表内不触发。

检查：`npm run typecheck`、`npm run build`、`npm test`；浏览器交互见 `tests/file-editor-ui-test.mjs`，桌面编辑见 `tests/file-editor-electron-test.mjs`。

编辑器将返回、项目／文件路径、保存时间、预览／源码、查看改动、@引用及更多操作放在一行；保存按钮仅在草稿改动时出现，没有单独底栏。Markdown 默认在预览画布中直接编辑，修改先保留在草稿中，点击保存后写盘；源码视图使用同一草稿。打开文件自动将路径引用附加到当前对话，手动再次引用去重；预览或源码选区可用浮动按钮另附行号。Git 改动可在标题栏切换差异视图；编辑时遇到外部修改显示重新加载／对比提示。标题缩至约 27px／20px，行内代码跨行保留底色。聊天右侧的问题导航仅在悬停标记时显示深色小提示。编辑器与聊天默认按 45／55 分配剩余宽度，拖动分隔条后记住比例。表格单元格中的代码不折行，宽表格内部横向滚动。附件位于输入框内部，非零上下文占用至少显示 2px。目标服务生成的完整提示信封以居中事件行呈现，相邻相同目标合并计数，原始消息不变；普通用户消息不合并。

设计验收：`tests/workspace-design-ui-test.mjs` 使用隔离 Git 项目和零模型调用的测试消息，检查目录树、改动圆点、工具输出、复制、设置入口与三栏尺寸；`tests/goal-pill-test.mjs` 检查目标入口迁移。

## 智能体工作中

连续的同模型助手步骤共用一个标题（工具结果不打断分组；用户／自定义消息或模型变化会分组）。首条助手消息尚未出现时，工作状态先显示同款 pi／模型／时间标题。原始消息 ID、搜索和编辑语义保留。聊天区只保留一条三点依次跳动的任务提示，按实际工具区分“正在运行 bash”“正在读取文件”，或分析／生成回复；前三秒隐藏计时，减少动态效果设置下停止动画。实时思考不显示折叠箭头，结束后恢复。底栏“工作中”使用同款三点动画，输入框不加工作状态圆点。

工作中输入框显示“排队”“插队发送”和停止；提示与快捷键同步：Enter 插队，⌘Enter（Windows 为 Ctrl+Enter）排队，结束后恢复普通发送提示。空输入时发送按钮禁用，排队使用 followUp、插队使用 steer。命令卡片统一提供换行、展开、全屏、复制、折叠；仅悬停／键盘焦点时显示，触屏常显；运行中的命令保留停止入口。命令默认工作区不重复标注，明确的其他路径才显示（当前用户目录缩写为 `~`）。只压缩带行号搜索结果冒号后的缩进，不修改普通代码空格；长输出可横向滚动，右侧尚有内容时显示渐隐边缘。

`tests/agent-working-ui-test.mjs` 验证工作状态、计时阈值、分组、两种发送指令、按钮一致性、改动筛选、输出滚动与回到底部按钮在 1600/900/390px 下对齐输入框；`tests/unit/agent-activity.test.ts` 验证分组边界、工具状态、路径与输出处理。

工作中输入内容后，“插队发送”采用深色主按钮，“排队”采用描边次按钮；空输入时两者禁用。已记录的思考耗时从 1 秒起显示，未记录的耗时不推测。编辑工具的 diff 显示文件路径、增删统计、行号及整行底色。文件栏将改动数量收进筛选按钮，目录保留数字，文件显示 M/A/D。侧栏当前对话始终高亮，新对话置顶并立即可见；当天显示时间，昨天显示“昨天”，设置入口带齿轮图标；目标完成提示也使用与目标设定一致的事件行。

服务端将新产生的真实思考耗时写入 `<dataDir>/thinking-durations.json`，按会话文件和消息时间戳匹配，重启后仍可展示。此前没有记录耗时的旧消息保持未知，不填入估计值。

## 折叠对话与文件栏

历史消息摘要、展开消息和输入框共用 780px 内容宽度。摘要以与普通消息一致的灰色用户标记或紫色 π 标记识别角色；右箭头表示可展开，展开后用向下箭头收起。“回到底部”靠输入框右缘，停在输入框上方。命令卡片按钮垂直居中；grep 输出自带行号时复用该行号，不再叠加序号；横向溢出的内容在右侧渐隐。

非 Git 目录在文件栏和底栏明确显示“非 Git 仓库”，文件栏不显示改动筛选。文件栏下方的“本次对话涉及”从已完成及正在生成的工具调用提取当前工作区文件，点击即可预览；工作区外路径不列入快捷入口。项目行时间显示最近会话的修改时间；没有会话时回退到项目最近使用时间。验收脚本 `tests/workspace-folded-ui-test.mjs` 使用隔离的非 Git 工作区和零模型调用消息检查这些状态。

相邻可见消息间隔超过 30 分钟时显示居中时间分隔线；消息时间和分隔线悬停可查看完整日期。思考行有无耗时均使用一致的箭头和文字基线，缺失耗时显示“未记录”；问题导航只标用户问题，标记高度按消息在整个滚动内容中的位置计算。输入框空白时即使获得焦点也保持灰色边框，只有聚焦且有输入内容时使用强调色；下方快捷键提示仅在消息输入区聚焦时显示。相关交互由 `tests/workspace-folded-ui-test.mjs` 验证。

代码文件默认用浅色纸面与低饱和紫／灰绿语法色，长行横向滚动；“更多”菜单可切换换行，只读阅读时续行使用悬挂缩进。设置 → 外观提供浅色、深色、跟随系统三种代码文件配色，偏好保存在当前浏览器；聊天命令输出始终保持深色。代码文件标题栏明确显示“只读／编辑”状态和 Git 改动入口；行号边显示新增、修改、删除标记，数据来自现有 SCM filediff 响应。消息导航标记固定在聊天滚动区右缘，编辑重问按钮悬停时位于气泡下方。

连续的 `read` 工具调用合成一条可展开的读取记录；工具结束后立即显示绿色“完成 · 耗时”，模型继续处理时由底部三点提示“等待模型”。展开的读取卡片以文件路径代替原始 JSON 参数，路径可打开完整输出；Markdown 的 YAML frontmatter 以小字段表显示，正文与代码输出默认仅显示前 10 行，可展开全部。技能卡片折叠时只显示技能名，完整路径保留在悬停提示与展开状态。文件栏“本次对话涉及”对根目录文件不显示空目录行，标题汇总读取／搜索等操作数量；只有多种操作并存时，条目才逐项标注操作。回到底部按钮挂在输入区顶部的独立留白中，不遮住消息或工具卡片。相关回归覆盖于 `tests/agent-working-ui-test.mjs` 和 `tests/unit/read-presentation.test.ts`。

带 `echo "=== LABEL ==="` 标记且输出按同一顺序出现的 `&&` 命令，才显示“步骤／原始”切换；未标记或无法可靠对应的命令保持原始输出。步骤状态依据实际输出标记、结束状态和退出码推导；grep/rg 无匹配（退出码 1）呈灰色，不算失败。部分失败的步骤卡片默认展开失败项，仅错误行着红色；完全失败且有可解析 `file:line` 诊断时显示文件行号链接和可展开原始输出。链接打开工作区内文件并定位行，工作区外路径不打开。连续子代理工具调用按真实工具结果合并，缺少子代理内部步骤或统计时不补造数据；grep 工具调用显示可展开的搜索摘要。对应逻辑见 `web/src/bash-steps.ts`，回归见 `tests/unit/bash-steps.test.ts` 与 `tests/agent-working-ui-test.mjs`。
